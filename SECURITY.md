# Security policy

## Supported versions

agentforge is in early development and has no releases yet. Security fixes are made on the `main`
branch only.

## Report a vulnerability

**Don't report security problems in a public issue, pull request or discussion.**

Report them privately through GitHub:
[Report a vulnerability](https://github.com/rlpotter3/agentforge/security/advisories/new)
(also under the repository's **Security** tab). You need a GitHub account.

Please include:

- what the problem is and what someone could do with it;
- the steps to reproduce it, and the commit you tested;
- any suggested fix.

Don't include real credentials or other people's data. If you found an exposed secret, say where it
is without copying its value, and don't use it.

## What to expect

agentforge has one maintainer, so these are goals, not guarantees:

- an acknowledgement within 7 days;
- an assessment, and a plan if the report is confirmed, within 14 days.

Please give us a reasonable time to fix a confirmed problem before you make it public. We will
credit you in the advisory if you would like.

## Testing safely

Test only against your own copy of agentforge, with your own accounts and keys. Don't test against
systems or data that belong to other people.
